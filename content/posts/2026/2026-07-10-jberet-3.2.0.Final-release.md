The JBeret `3.2.0.Final` has been released:

- [Release v3.2.0.Final · jberet/jsr352](https://github.com/jberet/jsr352/releases/tag/3.2.0.Final)
- [Releasev3.2.0.Beta2 · jberet/jsr352](https://github.com/jberet/jsr352/compare/3.1.0.Final...3.2.0.Beta2)

## Notable Changes

- [JBERET-665](https://github.com/jberet/jsr352/pull/745) Deprecated the `org.jberet.spi.PartitionInfo` class.

## Notable Bug Fixes

- [JBERET-612](https://github.com/jberet/jsr352/pull/654) Fixed a class loading issue with DDL files when running in Quarkus dev mode.
- [JBERET-395](https://github.com/jberet/jsr352/pull/671) Fixed exit code returning 0 when `org.jberet.se.Main` failed to start a job.
- [JBERET-645](https://github.com/jberet/jsr352/pull/716) Replaced the deprecated `DefaultCacheManager` constructor for Infinispan compatibility.
- [JBERET-654](https://github.com/jberet/jsr352/pull/721) Removed usage of the deprecated `java.security.AccessController`.
- Fixed a case where [ChunkRunner spawned excessive threads](https://github.com/jberet/jsr352/pull/672).
